## Reviewed first slice

Tools inspect exact board/committee, beneficial ownership/control, compensation, auditor/opinion/fees, related-party, capital-allocation, restatement and litigation observations for one issuer. Every fact retains entity/person/role identifiers as disclosed, period/effective/publication dates, jurisdiction, source span/document, correction lineage, information state and receipt.

Families remain independent and missing families are explicit. Name matching never silently equates people/entities. Calculated counts/tenures/concentrations expose exact definitions and leaves. Original records remain controlling over summaries.

Provider/document extraction must use bounded, source-specific adapters; pure domain modules own typed facts and deterministic projections.

## Explicit exclusions

No governance score/grade, independence or management-quality verdict, fraud/controversy inference, materiality/legal judgment, peer ranking, recommendation, or investment conclusion.
