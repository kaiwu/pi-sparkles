## Reviewed first slice

Tools inspect/list licensed transcript identities, search exact text, return bounded speaker-aware excerpts, and align caller-selected topic passages across two transcripts. Facts retain issuer/event/period, event/publication/retrieval times, provider/source kind, language, participant/speaker identity and role as supplied, character offsets, corrections, licence and content hash.

Search and excerpting are deterministic and never rewrite source text. Unknown/misattributed speakers, redactions, missing sections and provider corrections remain visible. The shell enforces excerpt, result and context budgets plus cancellation and rights.

Acceptance covers speakers, repeated phrases, offsets, multilingual text, corrections, missing/ambiguous participants, bounded search and receipt stability.

## Gates and exclusions

Blocked on a transcript licence permitting the intended use. No unlicensed full-text reproduction, sentiment, intent/deception inference, topic importance, guidance extraction by default, summary verdict, recommendation, or trading action.
