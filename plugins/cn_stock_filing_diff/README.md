This is the mainland-owned filing-diff contract for 年报, 半年报, 季报, 业绩预告, 业绩快报 and 更正公告. It aligns exact Chinese section/table identities and returns bounded raw or named-normalized changes with original text, anchors, change types, document/event identities, publication/effective dates, correction lineage, source receipts and omissions.

CN form labels and Chinese originals remain controlling. It composes `finance_cn_documents` and shared pure diff mechanics without importing HK/US document domains. Unsupported PDF structures, arbitrary archives, OCR, ambiguous issuer/version, or conflicting corrections fail closed.

Acceptance covers Chinese headings/tables, corrections, distinct event classes, raw/normalized preservation, duplicate anchors, attachments, budgets, and stable hashes.
