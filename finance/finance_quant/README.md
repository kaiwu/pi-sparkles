# finance_quant

Pure point-in-time research laws for Tier 4. The package verifies canonical
`finance_replay` universe and dataset manifests, preserves exact source
lexemes and receipts, and implements bounded CN market/screen projections,
event-study calculations, and single-factor cross-sectional studies.

It performs no provider access, storage, search, model selection, parameter
optimization, interpretation, recommendation, or trading effect.
