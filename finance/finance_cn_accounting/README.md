# finance_cn_accounting

Experimental mainland-China accounting vocabulary over
`finance_market_accounting`. It retains Chinese line labels and reported scale,
exact numeric lexemes, normalized units, Chinese/IFRS/other standards,
consolidated or parent scope, report class, audit state, restatement state,
source document, and evidence identity.

The package performs no tag preference or restatement selection. A fact must
belong to the same exact issuer as its source document. Provider decoders and
audited executable mappings remain source-owned work.
