# finance_transcript

Pure, deterministic transcript mechanics for licensed or caller-owned text.
The package validates exact issuer/event/source/rights identity, speaker-aware
segments, offsets, correction lineage, source-content and packet hashes. It can
search exact text, return bounded neighboring segments, and align exact query
matches across two transcript versions without rewriting or interpreting them.

It never infers sentiment, intent, deception, importance, or guidance.
