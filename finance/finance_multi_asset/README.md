# finance_multi_asset

Pure exact laws for the Tier 5 macro and multi-asset product. Modules retain
family-specific identity, source, time, entitlement, correction and unit facts;
perform only explicitly named calculations; and compose labelled legs without
inventing another equity track.

The package imports no Pi, promises, HTTP, storage, clocks or credentials.
Content hashes bind caller-owned import bytes and typed handoffs but are never
provider signatures or authority proof.
