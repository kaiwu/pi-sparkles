# finance_hk_testkit

Experimental seed-stable, synthetic-only Hong Kong scenarios for adapter and
plugin contract tests. The package composes HK identity, calendar, rules,
document, and accounting constructors while remaining independent of the CN
testkit and mainland assumptions.

The catalogue covers Main Board, GEM, depositary receipts, leading-zero codes,
listing-specific board lots, suspension, parallel Chinese/English reports,
corrections, HKFRS/IFRS distinction, exact large numeric lexemes, reported
scale, and split sessions. Real HKEX/HKEXnews fixtures require their own access
and redistribution approval.
