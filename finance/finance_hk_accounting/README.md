# finance_hk_accounting

Experimental Hong Kong accounting vocabulary over
`finance_market_accounting`. It retains original Chinese or English line
labels, exact numeric lexemes, reported scale, normalized units, HKFRS/IFRS or
other standard, statement scope, period, report class, audit/restatement state,
source document, and evidence identity.

The package performs no hidden language, mapping, or restatement preference and
cannot attach a fact to a different issuer's document.
